# 🧠 Building Long-Term Memory Agents with LangGraph

This repository contains learning notes and code from the **"Long-Term Agentic Memory with LangGraph"** course, created by LangChain and taught by its Co-Founder & CEO, **Harrison Chase**. The course explores how to build intelligent agents that can retain and use long-term memory to become more helpful, context-aware, and personalized over time.

---

## 📌 Key Learnings

- Deep dive into the three types of memory used in AI agents:
  - **Semantic** – facts and knowledge
  - **Episodic** – past experiences and examples
  - **Procedural** – instructions and workflows
- Applying memory concepts to practical agent workflows
- Techniques for improving agent behavior using memory, routing, and prompt design

---

## 🛠 Project Overview

As part of the course, a **personal email assistant** is built that can:

- **Triage** incoming emails using a smart router  
- **Respond, schedule, or notify** based on message context  
- **Store and retrieve long-term user information**  
- Use memory tools to adapt behavior and personalize responses

---

## 🎓 Course Content

The course walks through:

- Core memory concepts for agents  
- Building a baseline email assistant  
- Step-by-step addition of:
  - **Semantic memory**
  - **Episodic memory**
  - **Procedural memory**
- Techniques for improving performance with feedback and prompt tuning
